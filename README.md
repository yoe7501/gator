# Gator

A command-line RSS feed aggregator written in Go. Register users, add and follow feeds, let gator fetch posts in the background, and browse the latest posts from your terminal.

## Requirements

- Go 1.23+
- PostgreSQL 15+
- [goose](https://github.com/pressly/goose) (database migrations)
- [sqlc](https://sqlc.dev) (only needed if you change the SQL queries)

## Setup

1. **Clone the repo**

   ```bash
   git clone https://github.com/yoe7501/gator.git
   cd gator
   ```

2. **Install the tools**

   ```bash
   go install github.com/pressly/goose/v3/cmd/goose@latest
   go install github.com/sqlc-dev/sqlc/cmd/sqlc@latest
   ```

3. **Create the database**

   ```bash
   sudo -u postgres psql
   ```

   ```sql
   CREATE DATABASE gator;
   ALTER USER postgres PASSWORD 'postgres';
   ```

4. **Run the migrations**

   ```bash
   cd sql/schema
   goose postgres "postgres://postgres:postgres@localhost:5432/gator" up
   cd ../..
   ```

5. **Create the config file** at `~/.gatorconfig.json`:

   ```json
   {
     "db_url": "postgres://postgres:postgres@localhost:5432/gator?sslmode=disable"
   }
   ```

   Gator adds `current_user_name` to this file when you register or log in.

6. **Build and install**

   ```bash
   go install .
   ```

   Or run directly with `go run . <command>` instead of `gator <command>`.

## Commands

| Command | Description |
|---|---|
| `register <name>` | Create a user and log in as them |
| `login <name>` | Switch to an existing user |
| `users` | List all users (current one is marked) |
| `reset` | Delete all users (and their feeds, follows, and posts) |
| `addfeed <name> <url>` | Add a feed and follow it |
| `feeds` | List all feeds and who added them |
| `follow <url>` | Follow an existing feed |
| `following` | List feeds you follow |
| `unfollow <url>` | Stop following a feed |
| `agg <interval>` | Fetch feeds on a loop, e.g. `agg 30s` |
| `browse [limit]` | Show your latest posts (default 2) |

## Example

```bash
gator register yoel
gator addfeed "Wags Lane" "https://www.wagslane.dev/index.xml"
gator agg 30s          # leave running in one terminal
gator browse 5         # in another terminal
```

Don't set the `agg` interval too low. Fetching a site every second is rude and can get you blocked.

## Project layout

```
internal/config/     reads and writes ~/.gatorconfig.json
internal/database/   code generated by sqlc (do not edit)
sql/schema/          goose migrations
sql/queries/         SQL queries that sqlc turns into Go functions
```

## Changing the database

1. Add a new numbered file in `sql/schema/` and run `goose ... up`.
2. Add or edit queries in `sql/queries/`.
3. Run `sqlc generate`.
